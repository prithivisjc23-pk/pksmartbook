# Pksmartbook

Build a modern, mobile-friendly web application called SolluBook AI for small businesses in India. The app should allow shop owners to manage their business without needing accounting knowledge. Core features:

User registration and login.

A dashboard showing total sales, expenses, and balance.

Add, edit, and view sales and expense records.

Customer management and pending payment tracking.

Inventory and low-stock alerts.

Tamil and English language support toggle.

Clean, simple interface suitable for beginners.

Admin dashboard with separate permissions.

Responsive design for mobile and desktop. Use React and TypeScript. Start by creating a working UI and database schema for Supabase.
